## 4. Product-level gaps worth deciding on

1. **Nothing leaves the browser.** Booking writes to `localStorage` and prints a code like `PC-1405-728`; "tracking" reads it back only on the same browser; `handleRemoteSubmit()` only shows a toast ("کارشناس تا ۵ دقیقه تماس می‌گیرد") and posts nothing. Right now a customer can book a slot and **the shop never learns about it**. The `remoteModal` also has no field capture at all.
2. **Placeholder contact data.** JSON-LD phone is `+98-21-88880000`; address is Mirdamad/Paytakht; social buttons link to bare `https://ble.ir`, `https://eitaa.com`, `https://t.me`, `https://wa.me` (domain roots, no channels/handles); OG image is a `placehold.co` stub. All of this is what Google and customers read first.
3. **AI is real only if a key exists.** `apiKey = ""` by default, model `gemini-3-flash-preview`; visitors can paste their own key (stored in `localStorage`). Without one, `runLocalIntelligentEngine()` answers from keywords — genuinely nice work (Persian keyword sets for liquid damage, burning smell, thermal throttling, BSOD, HDD/IO, power), with graceful `AUTH_NO_KEY` / offline fallback. But the **Vision tab is the trap**: with no key it calls that same keyword engine against the *notes field*, so the uploaded screenshot is never analyzed while the UI says "تحلیل تصویری". Either wire a server-side key or make the fallback copy honest.
4. **Opening hours contradict each other.** Live badge: open Sat–Thu **09:30–20:30**. Calendar: Thursday **and** Friday are hard-blocked (`isWeekend = 5 || 6`). Modal copy: reception Sat–Wed **until 17:00**. Also the badge rebuilds `className` wholesale on each tick, which drops any class you add later.
5. **Dead references / stubs.** `checklistItemsContainer`, `checklistProgressText`, `checklistProgressBar` are read from JS but don't exist in the DOM (safely null-guarded, so no crash — but the diagnostic checklist UI is unreachable). `updateChecklistProgress()` is never called.
6. **Small stuff:** `new AudioContext()` per click (Safari caps these); `lockBodyScroll` uses inline `style.overflow` (fine, no scrollbar-gutter compensation on desktop); the header AI button is `hidden 2xl:flex` so it only appears ≥1536 px; `md:text-7xl` line-height was patched with `!important` (works, just worth knowing it's a patch).
