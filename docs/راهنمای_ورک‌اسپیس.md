# راهنمای ورک‌اسپیس — همه‌چیز از صفر

این سند توضیح می‌دهد **چه چیزی این‌جاست، چرا این‌جاست، و چطور با آن کار کنید**.
برای وضعیت لحظه‌ای و سابقهٔ تغییرات: `README.md` · برای فهرست ابزارها: `tools/README.md`.

---

## ۱. تصویر بزرگ

محصول، یک سایت تک‌صفحه‌ای فارسی/راست‌به‌چپ برای یک کارگاه خدمات کامپیوتر است: Tailwind + جاوااسکریپت خالص، **بدون بک‌اند، بدون فریم‌ورک، بدون مرحلهٔ build**. تمرکز سایت روی **پشتیبانی ریموت شبانه‌روزی** است و پذیرش حضوری (شنبه–چهارشنبه، ۱۰:۰۰–۱۷:۰۰) مسیر دوم است.

همه‌چیز در ورک‌اسپیس حول یک فایل می‌چرخد:

```
پشتیبان_رایانه.html   ←  تنها فایلی که ویرایش می‌شود (منبع اصلی)
        │
        │  python3 tools/ops/assemble_offline.py
        ▼
پیش‌نمایش_آفلاین.html  ←  بیلد تک‌فایلی: CSS و فونت‌ها داخلش in‌لاین شده، صفر درخواست شبکه
        │
        │  python3 tools/ops/preview_server.py   (http://localhost:8899)
        ▼
      پیش‌نمایش زندهٔ شما
```

بقیهٔ پوشه‌ها یا **ورودی بیلد** هستند (`assets/`)، یا **ابزار کار** (`tools/`)، یا **سند و شاهد** (`docs/`, `screenshots/`)، یا **آرشیو دست‌نخوردهٔ فایل‌های اولیهٔ شما** (`uploads/`).

## ۹. دستورهای کاری (تقلب‌نامه)

```bash
cd /home/user

# ۱) بعد از هر ویرایش در پشتیبان_رایانه.html
python3 tools/ops/assemble_offline.py      # ساخت بیلد + تست پوشش CSS

# ۲) آزمون رگرسیون (اجباری)
python3 tools/audit.py                     # باید بگوید PASS 83 · FAIL 0

# ۳) آزمون دقیق‌تر (وقتی دسترس‌پذیری/رفتار را دست زدید)
python3 tools/verify_package2.py           # ALL CHECKS PASS
python3 tools/check_review.py              # سلامت تختهٔ بازبینی

# ۴) پیش‌نمایش زنده
bash run-preview.sh                        # ساده‌ترین راه (روشن/خاموش را خودش می‌فهمد)
python3 tools/ops/preview_server.py        # → http://localhost:8899

# ۵) عکس‌برداری (نیاز به Playwright)
python3 tools/shots/shots_f16.py
python3 tools/shots/shots_credits_final.py
```

**راه‌اندازی محیط تازه (سندباکس نو):** Playwright و `node_modules` در اسنپ‌شات ذخیره نمی‌شوند:

```bash
pip install playwright && python3 -m playwright install chromium
sudo python3 -m playwright install-deps chromium
cd tools/ops/tailwind && npm i -D tailwindcss@3.4.17     # فقط اگر CSS را بازسازی می‌کنید
```

## ۱۰. قواعد طلایی

1. **فقط `پشتیبان_رایانه.html` را ویرایش کنید.** بیلد و CSS هر دو بازساخته می‌شوند.
2. **کلاس Tailwind تازه** ⇒ اول CSS را بازسازی کنید، وگرنه بیلد FAIL می‌دهد.
3. **`tools/patches/` را دوباره اجرا نکنید** — اثرشان داخل فایل هست.
4. **هر تغییر تازه باید آزمون بگیرد**؛ اگر آزمون ندارد، دلیلش را در `README.md` بنویسید.
5. **`uploads/` دست‌نخورده** می‌ماند.
6. نوشتار: «**شبانه‌روزی**» هرگز «۲۴/۷» · هیچ قیمتی بیرون طرح‌های Care · نام تجاری در توصیف خدمات حضوری نه.
