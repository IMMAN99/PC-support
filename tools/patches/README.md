# tools/patches/ — پچ‌های یک‌بارمصرف (سابقه، نه اجرا)

هر فایل یک بازنویسی متن‌محور روی `پشتیبان_رایانه.html` است که **قبلاً اجرا شده** و اثرش داخل فایل نهایی هست.
این‌ها را برای «تاریخ تغییرات» نگه داشته‌ام؛ **دوباره اجرا نکنید.**

* هر پچ یک نشانگر یکتا در HTML جا می‌گذارد (`<!-- ROUND-… -->`) و در اجرای دوم با پیام خطا متوقف می‌شود.
* ترتیب زیر همان ترتیب واقعی کار است؛ پچ‌های بعدی روی خروجی پچ‌های قبلی نوشته شده‌اند.
* اگر لازم شد از صفر بازسازی کنید: از `uploads/PC_Support.html` شروع کنید و پچ‌ها را **به همین ترتیب** اجرا کنید.
